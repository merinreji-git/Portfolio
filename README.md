# Portfolio Website

This is a static GitHub Pages-ready portfolio for SEO, digital marketing, content, and design work.

## What to Replace

- Add your CV at `assets/Merin-CV.pdf`.
- Replace `hello@example.com` in `index.html` with your email.
- Replace placeholder result numbers with confirmed metrics.
- Add real company logos or keep the text logo strip.
- Replace the design tiles with exported Canva images, videos, or linked case study pages.
- Add screenshots from GA4, Search Console, rankings, social analytics, and before/after design work.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, `README.md`, and the `assets` folder.
3. In GitHub, open Settings > Pages.
4. Set Source to "Deploy from a branch".
5. Choose the `main` branch and `/root`.
6. Save, then wait for GitHub to publish the site URL.
